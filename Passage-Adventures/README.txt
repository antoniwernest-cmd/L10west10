PASSAGE ADVENTURES

Open index.html. Keep this folder inside the complete Adventures deployment.
30 stories each have a distinct Pre-A, A, AA, AAA and AAAA version: 150 passages.
Ten response formats for each version: 1,500 response activities.
Choose a story, level and response format. On narrow screens use Story and Respond.
All reading and tools fit the screen; no page scrolling is needed.
Sequencing, matching and sentence building use drag-and-drop with mouse or touch.
Drag again to move cards or return them to the bank. No arrow controls are needed.
Missing Words supports typing or word-bank selection. True/False gives immediate feedback.
Shuffle mixes story order while keeping earned credit and history.
Use the same picture ID, device and browser. Teacher tools exports Excel assessment.
Teacher voice uses code 259. Read-aloud can be replayed at different speeds.
AAAA increases content, vocabulary, inference and evidence demands.
STORY-CATALOG.json lists all story topics and word counts.
PASSAGE-CONTENT.json contains the five complete versions and their response tasks.
NEW-ARTWORK.json retains the new scene prompts. Other story pictures reuse existing Codex art.

Chromebook/tablet layout and touch checks: see ../CHROMEBOOK-AND-TABLET.txt.

NOVEMBER 1 READING LAYOUT
The index shows all 30 story pictures. Each opens the chosen level and response.
On small screens use Previous/More pictures to reach every picture without scrolling.
Use A− and A+ to change learning text size; Fit chooses a size for the available screen.
The preference is kept in browser storage. Text stays within the current screen.
Multiple-choice cards follow the text height, and the story picture sits beside the paragraph.
See ../READING-LAYOUT-CHECKS.json for current gallery, text and touch checks.

Pre-A uses shorter sentences, two-word matches and one missing word.
Cloze opens on the gaps. The full story unlocks after a correct response.
Listen reads the gapped prompt while the story is hidden. Try again hides the story again.


PASTEL PHONICS: PRE-A AND A
All 30 stories at each of these two levels use soft letter-group highlights.
Mint: common consonant blends. Lavender: consonant digraphs. Peach: vowel neighbours.
The same key is visible while reading and responding, including cloze and draggable cards.
The blank fields remain normal typing/word-bank controls. The full cloze story still opens only after a correct response.
Highlighting preserves spelling, punctuation, read-aloud, saved responses and earned credit.
Names, common silent-letter exceptions and multi-syllable vowel exceptions are excluded.
Trigraphs tch/dge are not labelled as two-letter consonant digraphs.
AA, AAA and AAAA use their existing presentation.

STORY LOCK AND PARENT ASSESSMENT
1. Answer all ten response activities for one story at the chosen level.
2. Lock in answers appears only when every response is fully filled in. Answers can be incorrect.
3. Choose Lock in answers to freeze this story’s final responses and see Call your teacher.
4. Teacher review uses code 259, the same code as Teacher voice.
5. Use Report for the parent summary and Answers to inspect each saved question, student response and expected answer.
6. Add an optional student name, support level, assessment type and note for parents.
7. Save PDF or Save PNG. The same parent-friendly snapshot includes all ten activity results, answer checks, hints/listens, strengths and next steps.
8. After a report is saved/prepared for download, Start something new returns to All adventures. The picture ID and previous locked assessment remain saved in this browser.

Locked responses cannot be changed with Try again, Shuffle or answer controls. Reopening a locked story returns to the teacher handoff. Older progress remains compatible.
A cancelled or failed Save As keeps the locked answers and allows another save attempt.
The PDF is one A4 portrait page; the PNG is 1600 x 2264 pixels. The report works offline using the bundled pdf-lib 1.17.1 (MIT; see vendor/pdf-lib-LICENSE.md).
Native Save As is used when available. Other browsers use a normal file download.
File saving API reference: https://developer.chrome.com/docs/capabilities/web-apis/file-system-access
Checks: ../STORY-LOCK-ASSESSMENT-CHECKS.json.
